## nutrition.py — 영양정보 계산

레시피의 재료와 용량으로 1인분 영양정보를 계산한다.
칼로리를 눈대중으로 적으면 실제와 60% 넘게 어긋나므로 손으로 적지 않는다.

```bash
python3 tools/nutrition.py ../recipes.json   # 현재 값과 계산 값 비교
```

`recipes.json` 에 반영하려면 `compute()` 를 불러 `calories` 와 `nutrition` 을 덮어쓴다.
결과는 10 단위로 반올림한다 — 어림값임을 숫자 모양으로 드러내기 위함이다.

### 표를 갈아끼우려면

`NUTRI` 는 재료 100g당 (열량/탄수/단백/지방) 이며 식품성분표의 통상값이다.
[식약처 식품영양성분 DB](https://various.foodsafetykorea.go.kr/nutrient/) 원본 파일을
구하면 이 표만 바꾸면 되고 나머지 구조는 그대로다.

### 알아둘 것

- 튀김 기름은 붓는 양이 아니라 **흡수량(재료 무게의 10%)** 으로 잡는다.
  이 보정이 없으면 튀김 요리가 3000kcal 로 나온다
- `NUTRI` 에 없는 재료가 있으면 계산이 실패한다. 조용히 0 으로 넘어가지 않는다
- 값은 어림값이다. 완성품 칼로리는 공개 출처끼리도 2배씩 차이가 난다.
  다만 "이 재료를 이만큼 넣으면 이 정도"라는 근거가 남는다
