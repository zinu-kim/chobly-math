# 하야의 냉장고

냉장고에 있는 재료로 오늘 뭘 해 먹을지 골라 주는 앱. 아내가 혼자 쓴다.

재고 관리가 목적이 아니다. **레시피 추천이 앱의 본체**이고 냉장고는 힌트일 뿐이다.

```
https://zinu-kim.github.io/chobly-math/fridge/
```

## 어떻게 쓰나

1. **냉장고** 탭에 있는 재료를 이름만 적어 둔다 (수량·유통기한 없음)
2. **홈**에서 추천 다섯 개를 받는다
   - `나라` / `자리` 칩으로 범위를 좁힌다. 양쪽 다 `자유`가 기본
   - 입력창에 "새우를 활용한 매운 요리" 처럼 적으면 추천이 그 기준으로 바뀐다
3. 카드를 누르면 **레시피**가 열린다. 재료·조리순서·영양정보가 다 들어 있다
   - `●` 는 냉장고에 있는 재료, `○` 는 없는 재료
   - 유튜브 버튼을 누르면 그 요리 영상 검색이 열린다
4. 마음에 들면 `♡` 로 **즐겨찾기**에 담는다

냉장고를 바꿔도 추천은 바로 안 바뀐다. 홈에서 **다시 추천**을 눌러야 반영된다.

## 설치

아내 폰 크롬에서 위 주소를 열고 → 메뉴 `⋮` → **홈 화면에 추가**.
주소창 없이 전체 화면으로 뜬다. 처음 한 번만 인터넷이 필요하고, 그다음부터는
비행기 모드에서도 추천·레시피·냉장고 편집이 다 된다.

## 무엇을 쓰지 않나

- 서버 없음, 계정 없음, 동기화 없음. 저장은 폰 안에만 (localStorage)
- 실행 중에 AI를 부르지 않는다. 추천은 내장 레시피를 태그로 걸러 만든다
- 유료 API·유료 호스팅 없음. 전부 무료

## 파일

```
index.html               앱 전체 (인라인 CSS/JS)
recipes.json             레시피 데이터
manifest.json            설치 정보
sw.js                    오프라인 캐시
icon-*.png               홈 화면 아이콘
```

## 레시피 추가

`recipes.json` 에 항목을 넣고 푸시하면 된다. 아내 폰은 다음 실행 때 알아서 받아 간다.

필드와 태그 어휘는 **닫혀 있다.** 목록에 없는 값을 새로 만들면 추천이 어긋난다.
규칙은 [`../FRIDGE_SPEC.md`](../FRIDGE_SPEC.md) 6장에 있다.

현재 40개가 들어 있다. 목표는 1000개다.
