| 앱 | 경로 | 쓰는 사람 | 문서 |
|---|---|---|---|
| 🧮 **초연이의 수학문제 생성기** | `/`, `kid/`, `parent/`, `shared/` | 아빠·초연이 | [SPEC.md](SPEC.md) |
| 🧊 **하야의 냉장고** | `fridge/` | 아내 | [FRIDGE_SPEC.md](FRIDGE_SPEC.md) · [fridge/README.md](fridge/README.md) |

한쪽을 고칠 때 다른 쪽 파일은 건드리지 않는다. `shared/` 는 수학 앱 전용이며

## 🧮 초연이의 수학문제 생성기

초등학교 5학년 딸을 위한 수학 문제 생성·풀이 앱. 두 개의 PWA로 되어 있다.

| 앱 | 주소 | 쓰는 사람 |
|---|---|---|
| 문제 만들기 | `/parent/` | 아빠 |
| 문제 풀기 | `/kid/` | 초연이 |

### 어떻게 돌아가나

1. 아빠가 문제 사진을 넣는다.
2. **앱 안에서** 글자를 읽어 보여준다. 아빠가 확인하고, 틀리면 고치거나 다시 읽힌다.
3. 확정된 텍스트로 프롬프트를 만들어 복사 → Claude 또는 ChatGPT에 붙여넣고 답변을 가져온다.
   사진은 여기서 다시 넣지 않는다.
4. 만들어진 문제 5개를 확인하고 보낼 것만 고른다.
5. 코드로 만들어 카톡으로 보낸다. 초연이가 붙여넣으면 문제가 열린다.

API 키를 쓰지 않는다. 전부 무료로 돌아간다.

### 파일

```
index.html          앱 고르는 화면
parent/             아빠 앱
kid/                초연이 앱
shared/
  style.css         공통 스타일 (분수 표기·입력 위젯 포함)
  mathfmt.js        분수 세로 표기 / 입력 위젯
  validator.js      정답 판정 (값만 맞으면 정답)
  storage.js        이력 저장 / 공유코드
SPEC.md             요구사항 명세 — 코딩 전에 먼저 읽을 것
```

`SPEC.md` 가 유일한 기준이다. 코드를 고치기 전에 반드시 먼저 읽는다.

## 🧊 하야의 냉장고

냉장고에 있는 재료로 오늘 뭘 해 먹을지 골라 주는 앱. 아내가 혼자 쓴다.

- 실행 중에 AI를 부르지 않는다. 내장 레시피를 태그로 걸러 추천한다
- 비행기 모드에서도 다 된다. 저장은 폰 안에만
- 홈 화면에 설치해서 앱처럼 쓴다

쓰는 법·설치·레시피 추가는 [fridge/README.md](fridge/README.md),
요구사항은 [FRIDGE_SPEC.md](FRIDGE_SPEC.md) 를 본다.
