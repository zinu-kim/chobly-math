초연이의 수학문제 생성기

아빠 앱과 초연이 앱의 메뉴 구성·버튼·문제 표기를 실제로 눌러보며 확인하는 미리보기입니다. 화면 이동과 정답 채점은 실제로 동작하고, AI 호출·카톡 공유·저장만 흉내입니다. 문제 내용은 임의 샘플이며, 정답 입력칸 4종류(정수·분수·대분수·소수)를 다 보여드리려고 일부러 유형을 섞어놨습니다.

이 미리보기에서 봐주셨으면 하는 것

  1. 아빠 앱 3단계(검토) 화면 — 검산 불일치 경고와 [빼기] 흐름이 쓸 만한지. 5번 문제를 일부러 틀리게 넣어놨습니다.
  2. 정답 입력칸 크기 — S21(360px) 기준으로 맞췄습니다. 분수 칸이 손가락으로 누르기에 충분한지, 폴드 펼쳤을 때 안 늘어지는지.
  3. 단위 라벨 위치 — 입력칸 오른쪽 회색 글씨. 1번 문제가 mL로 서술되고 L로 답하는 케이스입니다.
  4. 오답 → 재시도 → 공개 흐름 — 일부러 틀리게 넣고 [확인]을 눌러보세요.
  5. 문제 글자 크기와 줄간격 — 5번은 표가 들어간 문제입니다.
  6. 홈 화면 이력 카드 — 파란 테두리 + NEW 배지로 신규 구분.
